# Milk-Tea — 奶茶点单小程序

**Milk-Tea** 是一套基于 **Spring Boot + MyBatis + MySQL + Redis + RabbitMQ + WebSocket** 的奶茶点单系统，包含微信小程序用户端与 Vue 管理后台（商家端）。系统支持在线下单、支付、订单追踪、评价与实时聊天，并对高并发场景做了性能优化（缓存、消息队列、秒杀）与数据统计功能。

---

## 🚀 主要功能

### 🧋 用户端（微信小程序）
- 注册 / 登录（支持微信授权登录）
- 商品浏览、商品详情
- 购物车管理
- 地址管理（新增/编辑/删除）
- 下单（自取 / 外卖）与微信支付模拟/集成
- 订单查询与状态追踪
- 订单完成后评价（评分 + 文本 + 图片）
- 在线联系商家（实时聊天 / 消息中心）
- 个人中心（用户信息管理、历史订单查看）

### 🏪 商家端（Vue2 + Element UI）
- 分类管理、商品管理、套餐管理
- 订单管理（接单/出餐/完成/取消）
- 评价管理（查看/回复/统计）
- 消息中心（实时接收用户消息并回复）
- 数据统计（销售额、订单量、热销商品、评价汇总 → ECharts 可视化）
- 店铺管理（营业状态设置）

### ⚙️ 性能与可靠性
- Redis 缓存（热点商品、会话、秒杀库存）
- 缓存空对象拦截非法请求，防止缓存穿透
- RabbitMQ 异步化订单/库存/通知处理，削峰填谷
- Redis + Lua 原子操作保证秒杀场景下的库存一致性
- 支付回调幂等处理保证交易一致性

### 💬 实时通信
- WebSocket 实现用户与商家间的即时消息（消息持久化）

---

## 🧰 技术栈

- **后端：** Spring Boot、MyBatis、Redis、MySQL、RabbitMQ、WebSocket
- **商家管理端：** Vue2 + Element UI + ECharts
- **用户点单端：** 微信小程序



## 🧠 改进方向与持续更新计划

- 本系统仍在持续完善中，未来将逐步补充更多功能与优化：
- **用户端迁移计划（微信小程序 → uni-app）：** 后续将把当前基于微信小程序的用户端重构为 **uni-app** 实现，并把完整的 uni-app 源代码同步上传到仓库。此变更的目标是提升跨平台适配能力（支持微信小程序、H5、App 等多端发布）、复用前端代码以降低维护成本，并方便后续在不同平台上快速迭代与测试。迁移工作将包括页面与组件的重构、与后端 RESTful 接口的兼容适配（保持 API 不变或提供兼容层）、必要的性能与体验优化（如本地缓存、网络请求重试、图片懒加载等）以及完整的构建与运行说明（包括依赖安装、编译与真机调试步骤）。迁移完成后，仓库中将新增 `frontend-uniapp/` 目录，包含项目源码、说明文档与打包发布脚本，便于开发者查看、运行与二次开发。
